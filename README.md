## Cara Menjalankan

Ikuti langkah-langkah berikut untuk menjalankan sistem pencarian rute:

### 1. Membuka Sistem

1. Download file **`jakgo_final.html`**.
2. Klik kanan pada file tersebut.
3. Pilih **Open with → Google Chrome**.

### 2. Memilih Halte Asal

Terdapat dua cara untuk memilih halte asal:

- **Melalui kolom pencarian:**  
  Ketik nama halte pada kolom **Asal**. Sistem akan memberikan saran halte secara otomatis.
  
- **Melalui peta:**  
  Aktifkan **mode Asal**, kemudian klik halte yang diinginkan langsung pada peta.

### 3. Memilih Halte Tujuan

Halte tujuan dapat dipilih dengan cara yang sama:

- Ketik nama halte pada kolom **Tujuan** dan pilih dari saran yang tersedia; atau
- Aktifkan **mode Tujuan**, kemudian klik halte tujuan langsung pada peta.

### 4. Mencari Rute

Setelah halte asal dan tujuan dipilih:

1. Klik tombol **Cari Rute**.
2. Sistem akan menjalankan algoritma pencarian rute.
3. Hasil rute akan ditampilkan pada panel informasi dan peta.

### 5. Melihat Hasil

Hasil pencarian terdiri dari beberapa bagian:

#### Panel Rute
Panel sebelah kiri menampilkan:

- Rute tercepat dan rute alternatif
- Waktu perjalanan
- Jarak perjalanan
- Jumlah halte
- Jumlah transit
- Tarif perjalanan
- Langkah perjalanan berdasarkan koridor

#### Peta
Peta akan menampilkan **jalur/rute perjalanan** dari halte asal menuju halte tujuan.

#### Panel A* Algorithm
Panel **A* Algorithm** menampilkan informasi mengenai proses pencarian, meliputi:

- Jumlah simpul yang diperluas (*expanded nodes*)
- Waktu komputasi
- Nilai **g(n)** sebagai biaya perjalanan dari titik awal menuju simpul saat ini
- Nilai **h(n)** sebagai estimasi biaya dari simpul saat ini menuju tujuan
